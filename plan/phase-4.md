# Phase 4 — Integrated qualification and bounded evaluation

## Goal

Implement the Qualification and evaluation contract in the approved Astra-era development brief. This is one independently acceptable outcome; ordinary implementation steps do not require child phases.

## Deliverables

- Complete integrated offline qualification and update the canonical public explanation.
- Prepare explicit live qualification and twelve-run comparative protocols with fixed tasks, independent acceptance, and outcome-level metrics.
- Keep live batches separately priced and operator-authorized; label unavailable capabilities and unrun experiments explicitly.

## Acceptance

- The implementation planner specifies focused behavioral checks through the repository toolchain for each changed contract.
- `./bin/check all` passes on the independently approved implementation candidate and again after tracked close writes.
- Every live model claim names observed evidence; local fixtures do not establish account entitlement or performance.
- User Demo: inspect the resolved role table and preset behavior in a disposable configuration for Phase 2; inspect entry-point and phase behavior for Phase 3; inspect the evaluation protocol and offline report for Phase 4. The implementation plan supplies exact safe steps for the relevant phase.
