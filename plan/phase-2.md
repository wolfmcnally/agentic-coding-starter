## Goal

Implement the Model routing contract in the approved Astra-era development brief. This is one independently acceptable outcome; ordinary implementation steps do not require child phases.

## Deliverables

- Add explicit Astra routing and model/venue effort validation across initial and resumed commands.

- User Demo: inspect the resolved role table and preset behavior in a disposable configuration for Phase 2; inspect entry-point and phase behavior for Phase 3; inspect the evaluation protocol and offline report for Phase 4. The implementation plan supplies exact safe steps for the relevant phase.
