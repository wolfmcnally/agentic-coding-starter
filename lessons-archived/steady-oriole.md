A resumable provider session must still be resumed through the repository
manager that owns role registration, timeouts, telemetry, and required-output
capture. Substantively useful work resumed through an ordinary task-message
surface cannot serve as accepted evidence when the manager did not observe it.

Supply the provider session id to the managed watcher. If unmanaged resume
already occurred, record it as rejected or superseded and reexecute the
unchanged candidate through the watcher; never retrofit evidence.
