A plan finding stayed open through four rounds. Each revision widened the
control, and each review found another route outside it. The work appeared to
be converging because every counterexample became more exotic.

The persistent defect was not the mechanism. It was the sentence claiming the
mechanism covered every member of a class when it actually covered a named set
of routes.

The finding closed as soon as the plan stated the true coverage, named the
residual routes, and explained why the remaining risk was acceptable.

**The rule candidate:** compare each coverage claim with what its mechanism
actually enumerates. Improve the mechanism where doing so is cheap and sound;
narrow the sentence to truth in every case. When a finding recurs against an
improving mechanism, ask whether the claim rather than the implementation is
what remains wrong.
