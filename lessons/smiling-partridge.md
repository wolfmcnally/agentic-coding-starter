A reviewer's attention follows the revision packet. A round spent verifying resolutions reads the changed paragraphs closely and the unchanged ones lightly, so the findings that were present from the start surface only once the packet empties — and each stratum costs one planner round plus one review round, with the plan-growth stop firing on the way.

**The rule candidate:** require the reviewer persona to state on its first pass whether its findings are the complete set it can raise against the current text, or to list the sections it did not examine; on later passes, require an explicit line naming the sections re-read in full, so partial coverage is visible to the orchestrator rather than inferred from a quiet round.

This is weaker under the primary-mode advisory default, where the report is advice and the pass ceiling is two, than it was under the delegated approval loop that produced it. It is filed rather than graduated because the fix is a persona edit whose cost lands on every review, and because the observation comes from one donor phase.
