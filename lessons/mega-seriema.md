Before scaling a model comparison, use its first predeclared cell to witness the complete native launch, review and delivery lifecycle. Fixture correctness and a green host suite prove different properties. An interactive harness's completion callback cannot be assumed to survive a print CLI exit; in the observed run, the evaluator's container lifetime followed that CLI and interrupted an unfinished role.

The operator selected repair followed by a separately identified comparison. The correction disables native background tasks for print invocations and requires an actual complete workflow witness before scaling. Its live effectiveness remains to be verified. Preserve the interrupted attempt as evaluator-affected evidence and distinguish correct code, workflow completion and model identity qualification; do not turn the interruption into a model failure or erase it from the record.
