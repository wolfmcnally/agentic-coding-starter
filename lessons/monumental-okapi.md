A phase authority stated a categorical rule and then described it as changing
a fixed number of sites. The rule reached more sites than the count. Both
statements looked authoritative, and the count looked like evidence that
someone had already enumerated the population.

The categorical rule remained true as the code evolved; the hand-written count
was a snapshot that could decay silently.

**The rule candidate has two sides.**

- Authors either provide an exhaustive, reproducible site table or state the
  categorical rule without a count.
- Implementers treat the rule as governing and mechanically re-derive the
  affected set whenever an enumeration disagrees.

A prose count is not a closed-world proof. If it matters, include the command
or procedure that regenerates it.
