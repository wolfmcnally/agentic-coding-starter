A bounded retrieval authorization counts requests, not the reasons discovered
afterward. Before each live-source probe, enumerate prior requests in the
current allowance and name the remaining slot it consumes. If none remains, do
not retrieve it. Evidence acquired outside the allowance stays disclosed and
cannot be credited retroactively; the remedy is a pre-request counter.
