Several internal sub-phases correctly declared that no meaningful user demo
existed yet. The parent phase still required one when the complete surface
shipped. Nothing in the exemption itself recorded that destination, so each
locally correct deferral looked indistinguishable from a closed obligation.

The obligation survived only because a person manually wrote it into a
parent-close checklist. Without that carrier, the final exemption would have
silently erased a requirement the parent still owed.

This applies beyond demos: deferred tests, migrations, documentation, and
operational checks all disappear the same way when a per-item exemption is
evaluated against a group-level requirement.

**The rule candidate:** an exemption that defers rather than dismisses names
the phase, milestone, or surface where the obligation lands. That destination
must be recorded somewhere its closing agent is required to read. Separate
"does not apply" from "applies later"; the second form requires a destination.
