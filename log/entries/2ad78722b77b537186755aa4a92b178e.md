One operator-approved plan, given in session on 2026-10-06, before any implementation. The operator asked whether the mutation-testing rules were serving the template, asked for research into current practice and for a way to make the rule work in a stamped project of any language, then approved the resulting plan with its five rulings as written.

**Authorized outcome.** A red witness becomes an observation instead of a sentence, and the committed patch corpus is retired. Three deliveries, each committed and pushed on its own gates:

1. **Witness receipts in, patch set out.** `bin/test-governance` gains a `witness` command that runs a named command green, lets the author plant a defect in the live tree, requires the same command to fail with a named text, restores the original bytes and verifies them, then appends a receipt. A pending witness makes every other subcommand refuse, so the pre-commit hook cannot pass a planted defect. The effectiveness corpus, its 24 patches, the assay, both recall floors, the dated effectiveness report and the two per-family evidence lists are removed, and the proof-estate schema moves to v4 by direct replacement.
2. **Backfill.** Each still-active admitted proof has the defect its ledger sentence names actually planted and observed. A claim that does not hold becomes a recorded repair. Then a missing receipt for an admitted or repaired proof becomes a validation error.
3. **Per-language mutation wrapper.** After a scratch spike of Python mutation tools, a `bin/mutate` wrapper joins the toolchain set that `stamp` adapts, reporting measured, partial or unmeasured and never gating.

**Rulings.** (1) The whole patch set and the 80% recall floors are retired, the historical-defect half included. (2) The witness runs in the live working tree, accepting that commits in that checkout are refused while one is open. (3) Receipts are backfilled for the already-admitted proofs. (4) Mutation-tool results never block a commit or a push. (5) Proofs whose contract is deleted with the patch set are retired on the primary's own comparison, since methodology work has no independent reviewer.
